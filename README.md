# 背得会：古诗带背 MVP

一个无需安装、双击即可运行的中文古诗背诵流程原型。当前示例为李白《行路难·其一》，保留了已经确认的 17 页交互、任意页滑动跳转、学生自写画面、逐句图文对应和间隔复习任务。

## 直接体验

1. 下载本仓库或解压发布包。
2. 双击 `index.html`。
3. 用页面顶部的滑动器跳到任意页测试。

这是纯静态网页，不需要服务器、Node.js、数据库或 API。学习时间、复习勾选等记录保存在当前浏览器的 `localStorage` 中；换浏览器、清理浏览器数据或换设备后不会自动同步。

## 当前学习流程

- 开始前选择当天开始背诵的时间。
- 每两句为一组：原句常驻 → 词义/句意理解 → 学生自己写脑中画面 → 小组串联。
- 六组完成后才梳理全诗逻辑，不能在开头要求学生先记整条框架。
- 整体画面页共六行，左侧为对应原句和学生自己的画面描述，右侧为具体插画，一一对应。
- 最后进行全文回忆，并生成睡前、次晨、第 3 天、第 7 天的复习任务。
- 第 3 天和第 7 天提醒可下载为标准 `.ics` 日历文件，兼容常见手机和电脑日历；同时保留豆包辅助入口。

## 继续开发

本项目刻意保持为单文件静态应用。修改 `index.html` 后直接刷新浏览器即可。任何修改都应先阅读：

1. `METHOD_BOUNDARY.md`
2. `HANDOFF_TO_DOUBAO.md`
3. `DELIVERY_CHECKLIST.md`

不要在没有原始方法材料依据的情况下自行增加教学方法、诗歌分析题或自动替学生生成个人画面。
